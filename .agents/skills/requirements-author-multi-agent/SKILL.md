# Requirements Author Multi-Agent

`requirements-author/SKILL.md` と `/home/harvestasya/workspace/mosaiclynx/.agents/project-context.md` を基盤にする。

## 実行

次の3観点を独立に確認する。サブエージェント機能が利用できれば分担してよいが、利用できない場合は現在のエージェントが観点ごとに別の作業メモを作り、最後に統合する。未使用のサブエージェントや並列実行を実施したと報告しない。

1. 根拠追跡: 要求、事実、制約、仮定、未決定事項、出典
2. 要求候補: 機能、非機能、セキュリティ、相互運用性、優先度、受け入れ条件
3. 品質・境界: 対象外、外部責任、過剰設計、競合、未解決のレビュー指摘

複数観点で一致しても、入力に根拠がなければ採用しない。矛盾は未決定事項へ送る。

## 出力

`requirements-author` の既定出力先と境界に従う。観点別メモ、実行台帳、レビュー成果物、仕様、設計、コードは出力しない。
