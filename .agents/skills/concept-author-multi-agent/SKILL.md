# Concept Author Multi-Agent

まず `concept-author/SKILL.md` と `/home/harvestasya/workspace/mosaiclynx/.agents/project-context.md` を読み、その境界・出力先・形式を基盤にする。

## 実行

独立した次の3観点を、他の結論を先に見せずに確認する。サブエージェント機能が利用できる場合は別担当へ分担してよいが、利用できない場合は現在のエージェントが同じ資料を3回の観点で個別に点検する。利用していないサブエージェントを使ったと報告しない。

1. 根拠: 事実、仮定、未決定事項、出典
2. 課題・価値: 背景、対象ユーザー、利用場面、目的、提供価値
3. 境界・リスク: v1、対象外、外部責任、前提、リスク、後続論点

各観点で入力にない機能、数値、制約、将来構想を追加しない。結果が矛盾する場合は元資料へ戻り、解消できなければ未決定事項として残す。

## 出力

最終成果物は `concept-author` の規則に従うコンセプトシート1つだけとする。観点別メモ、実行台帳、議論、要件、仕様、設計、レビュー結果をリポジトリへ残さない。既存ファイルを更新する場合は、ユーザーが明示的に更新を依頼したときだけ変更する。
